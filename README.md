# Сердце из частиц

Объёмное сердце из светящихся частиц.

Кулак собирает и сжимает его, открытая ладонь разбрасывает частицы. Рукой или мышью сердце можно облететь на 360°. Вторая рука меняет цвет, как и слова «розовый», «синий», «золотой», «фиолетовый». Чем громче голос, тем сильнее пульс.

Камера и микрофон работают только в браузере. Без них сердце собирается кнопками внизу экрана.

```powershell
npm install
npm run dev
```
